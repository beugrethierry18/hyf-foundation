# Reflection on Personal Portfolio Assignment

## 1. Identify and share 3 new things you learned from AI in the above task.

I learned how to structure a basic HTML page with semantic elements like headings and lists, but the most interesting part was understanding double-level flexbox properties. For example, on the div with class="social-links", AI applied flexbox to align the links horizontally, center them, and set spacing between the <a> elements. Then we applied flexbox properties on each <a> element to center the <i> icon inside the circle both horizontally and vertically. I also learned about the aria-label attribute, which gives textual descriptions to elements without visible text like icons and images - it's important for accessibility and good coding practice. Finally, I understood that AI can replace a person who only knows HTML and CSS like me (😂) - maybe even web developers, because AI knows more than humans!

## 2. Where did you have to tweak or correct Copilot's suggestions to suit your needs?

I had to tweak the CSS for the interests and skills section to display them horizontally in a row instead of vertically, using flexbox properties. I also adjusted the button centering by adding `display: block` and `margin: auto` to make it perfectly centered. Additionally, I added my personal social media links (LinkedIn, GitHub, CodePen) with Font Awesome icons and created specific hover effects for each platform to match my needs.

## 3. How would you explain the difference between using Copilot to generate code for you vs. using it as an effective learning partner?

Using Copilot to generate code means accepting suggestions without understanding them, which can lead to code you can't maintain or explain. Using it as a learning partner involves asking questions, understanding why it suggests certain approaches, and actively engaging with the code to build my own understanding. The key difference is whether I'm just copying code or actually learning the concepts behind it. Learning with AI is a great approach because it's available at any time and provides quick explanations, making it easier to understand complex concepts immediately.

## 4. Identify 3 risks of relying too much on AI tools when learning at HackYourFuture.

One risk is that I might not develop fundamental problem-solving skills if I always rely on AI for solutions. Another risk is that I could become dependent on AI tools and struggle to code independently during exams or job interviews. A major security concern is that AI tools often have deep access to our computers - they can analyze the entire system in seconds, create folders and files without intervention, and save data locally. This raises questions about whether the AI could inject malicious code or spyware into our computers without us knowing.
